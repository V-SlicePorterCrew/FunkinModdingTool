# Compiling

## Prerequisites

- [Haxe 4.2+](https://haxe.org/download/)
- [hmm](https://github.com/andywhite37/hmm)
  ```
  haxelib --global install hmm
  haxelib --global run hmm setup
  ```
- Visual Studio 2022 with "Desktop development with C++" workload

## Setup

```powershell
git clone https://github.com/V-SlicePorterCrew/FunkinModdingTool.git
cd FunkinModdingTool
hmm install
```

## Build & Run

### Windows

```powershell
lime test windows
```

### HTML5

```powershell
lime test html5
```
