# FunkinModdingTool

A cross-engine Friday Night Funkin' modding tool built with HaxeFlixel. Read, edit, and convert mods between engine formats — all from one place.

## Features

- **Format support** — Base FNF, V-Slice, Psych Engine (more planned)
- **Editors** — Chart editor, character editor, stage editor (in development)
- **Converters** — Convert mods between engine formats (in development)
- **GUI** — Built with HaxeFlixel, runs on Windows (more targets planned)
